# public-documents
Documents I want to share.

## How it works
Each topic is a folder in the repository root; put documents inside it.
On every push to `main`, the site is built (`python3 scripts/build.py`) and published with GitHub Pages
(enable it once under Settings → Pages → Source: GitHub Actions).

Share URLs like:
- Folder: `https://adamwadesmith.github.io/public-documents/example-topic/`
- Document: `https://adamwadesmith.github.io/public-documents/example-topic/hello.txt`
